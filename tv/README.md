# YouTube+tr TV

Отдельная ТВ-сборка на базе SmartTube 32.69 с русским закадровым переводом Яндекса. Мобильное приложение YouTube+tr и его настройки не меняются.

**[Скачать первую ТВ-версию](https://github.com/OsanRey/YouTube-tr/releases/tag/tv-v0.1.0)**

Сборка использует пакет `org.smarttube.stable` и заменяет стабильный SmartTube. Подпись собственная: поверх официального SmartTube она не установится; потребуется удалить его и затем войти в аккаунт заново. APK предназначен для Android 6.0+ и содержит ARMv7 и ARM64.

## Управление переводом

В видео откройте **⚙️ настройки плеера → Перевод Яндекса → Перевести на русский**. Все пункты доступны крестовиной и кнопкой OK. Настройки также доступны в общем разделе **Настройки → Перевод Яндекса**.

- Перевод на русский, автоматическое определение языка или ручной выбор.
- Ручное включение и выключение, автоперевод следующих видео.
- Громкость оригинала 0–100%, по умолчанию 20%.
- Пауза, перемотка, скорость и переход к другому видео синхронизируют отдельную дорожку перевода со штатным плеером.
- Вход в Яндекс и живые голоса через **Аккаунт Яндекса и живые голоса**. Вход и токены остаются только на устройстве. Используется тот же WebView OAuth-поток, что в Java-клиенте anddea; для входа может понадобиться экранная клавиатура.

Перевод зависит от доступности сервиса Яндекса и конкретного видео. По умолчанию используются живые голоса; для запроса нового перевода может понадобиться вход в Яндекс. Уже готовая дорожка может работать без входа. При отказе сервиса клиент один раз пробует другой тип голосов: обычные или живые. Ошибка «в видео нет речи» иногда относится к выбранному типу голосов, хотя другой тип возвращает перевод того же ролика.

Прямые эфиры не поддерживаются. Если сервис запрашивает исходный звук, приложение передаёт доступную прямую аудиодорожку; для форматов только SABR такой способ недоступен. Успешный перевод уже подготовленного ролика не гарантирует доступность перевода любого другого ролика.

Штатные возможности SmartTube сохраняются в исходном коде, но не все проверены отдельно. GmsCore для ТВ-версии не нужен: вход в YouTube реализован самим SmartTube. Обновления официального SmartTube отключены в этой сборке, чтобы не предлагать APK с другой подписью. Новые версии: [Releases YouTube-tr](https://github.com/OsanRey/YouTube-tr/releases).

## Проверка

4 ноября 2026 года сборка установлена вместо SmartTube 32.68 на X4 с Android 11. Система выбрала ARMv7. Проверены загрузка ленты, воспроизведение, навигация крестовиной/OK, включение русского перевода, пауза/продолжение и перемотка на 20 секунд. Русская озвучка подтверждена пользователем при прослушивании. После перемотки журнал показал одинаковые позиции видео и перевода; на паузе после воспроизведения разница позиций составляла примерно 0,2 секунды. Это проверка состояния плееров, не измерение акустической задержки.

Проверка подписи APK и шесть проверок protobuf пройдены. Выполнение на ARM64, вход OAuth Яндекса и отправка новой исходной аудиодорожки на устройстве отдельно не проверены. Это первый предварительный выпуск ТВ-версии.

## Сборка

Нужны Windows, Git, Python 3, JDK 17, Android SDK с платформой 36 и Build-Tools 36.0.0. Gradle 7.5 скачивается штатным wrapper; некоторые модули могут дополнительно загрузить Build-Tools 30.0.3.

```powershell
.\tv\build-tv.ps1 -JavaHome 'C:\path\to\jdk17' -AndroidSdk 'C:\path\to\Android\Sdk'
```

Скрипт получает закреплённые ревизии из `upstream.json`, применяет `prepare_source.py`, запускает проверки protobuf, собирает универсальный APK и подписывает его локальным ключом. Результат: `output/YouTube+tr-TV-32.69-tr1-universal.apk`. Ключ и его параметры сохраняются в игнорируемом `build-cache`; для дальнейших обновлений нужен тот же ключ. Секреты в исходники и APK не включаются.

Реализация ТВ-контроллера и настроек находится в `tv/java`. Клиент протокола и окно входа берутся из закреплённого anddea 4.3.0 с сохранением заголовков авторства; изменения для Java 8 и ТВ явно помечены. Исходный плеер, YouTube API, интерфейс и управление пультом предоставлены SmartTube и его модулями. Это изменённая сборка, не официальный релиз SmartTube или VOT.
