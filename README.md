# YouTube+tr

YouTube для Android с возможностями ReVanced Extended и закадровым переводом на русский через Яндекс VOT.

**[Скачать APK и GmsCore](https://github.com/OsanRey/YouTube-tr/releases/latest)**

Неофициальная сборка на основе [anddea/revanced-patches](https://github.com/anddea/revanced-patches). Реализация перевода основана на [ilyhalight/voice-over-translation](https://github.com/ilyhalight/voice-over-translation). Это конфигурация сборки существующих проектов, а не самостоятельная реализация переводчика.

## Возможности

- Блокировка рекламы и SponsorBlock.
- Фоновое воспроизведение.
- Управление жестами, настройки качества и скорости.
- Настройка интерфейса и возврат дизлайков.
- Закадровый перевод Яндекса, автоматическое включение перевода, выбор языка, раздельная громкость оригинала и озвучки.

Применены 74 стандартных патча anddea. Набор отличается от других сборок ReVanced; отдельные старые настройки интерфейса не поддерживаются выбранной версией YouTube.

## Установка

1. В [Releases](https://github.com/OsanRey/YouTube-tr/releases/latest) скачать `GmsCore-0.3.1.4.240913.apk` и `YouTube+tr-21.13.164.apk`.
2. Установить GmsCore (microG Services), затем YouTube+tr.
3. Открыть YouTube+tr и войти в Google-аккаунт.
4. Включить перевод по инструкции ниже.

Если совместимый ReVanced GmsCore уже установлен, повторно устанавливать его не требуется. Приложение использует пакет `anddea.youtube` и может стоять рядом с обычным YouTube и ReVanced с другим именем пакета.

GmsCore в этом релизе — проверенная на тестовом устройстве версия, а не последняя доступная. Её исходный выпуск: [ReVanced/GmsCore v0.3.1.4.240913](https://github.com/ReVanced/GmsCore/releases/tag/v0.3.1.4.240913). APK содержит только программу, без данных аккаунта.

## Настройка перевода

**Вы → ⚙️ Настройки → ReVanced Extended → Закадровый перевод → Yandex**.

Включить:

- **Перевод озвучивания**.
- **Язык оригинала:** автоопределение.
- **Язык перевода:** русский.
- **Automatically translate videos:** автоматический перевод.
- **Pause video while preparing translation:** пауза на время подготовки дорожки.

Громкость перевода по умолчанию — 100%, оригинала — 20%. Кнопка **«Я»** в плеере включает и выключает перевод. Долгое нажатие открывает быстрые настройки громкости и голосов.

Для запроса нового перевода **живыми голосами** нужен вход в Яндекс в этом же разделе. Уже подготовленный перевод может работать без входа. Если приложение просит авторизацию, войдите самостоятельно либо выключите «Живые голоса» и попробуйте обычный режим. Доступность зависит от видео и сервиса Яндекса.

`output/tablet-settings.json` описывает использованные настройки. Они применялись через интерфейс приложения на тестовом устройстве и **не зашиты в APK**. После новой установки их нужно включить самостоятельно.

Проверено 2 ноября 2026 года на **Xiaomi Pad 6 с Android 14**: установка, запуск, загрузка ленты, доступ к аккаунту, воспроизведение и русский закадровый перевод англоязычного видео. Русская озвучка подтверждена при прослушивании. Остальные функции отдельно не тестировались.

Подпись оригинального APK проверена Android apksigner: сертификаты Google совпали с сертификатами установленного оригинального YouTube. Подпись готового APK также проверена. Отчёт: `output/patch-result.json`, сведения о сборке: `output/build-manifest.json`.

Контрольные суммы APK и архивов исходников находятся в `SHA256SUMS.txt` каждого релиза.

## Самостоятельная сборка

Нужны **PowerShell 7+**, Java 21+ и около 6 ГБ доступной памяти для Java.

```powershell
git clone https://github.com/OsanRey/YouTube-tr.git
cd YouTube-tr
.\prepare.ps1
.\build.ps1
```

`prepare.ps1` загружает зафиксированные версии сборщика, патчей и оригинального YouTube и проверяет SHA-256. Если оригинальный APK уже есть, его можно указать:

```powershell
.\prepare.ps1 -SkipApk
.\build.ps1 -Java 'C:\path\to\java.exe' -Apk 'C:\path\to\youtube-21.13.164.apk'
```

Настройки патчей находятся в `build-options.json`. Результат: `output/YouTube+tr-21.13.164.apk`.

Ключ подписи создаётся локально: `build-cache/morphe.keystore`; резервная копия — `output/tablet-vot.keystore`. Сохраните его для собственных будущих обновлений. Ключ опубликованной сборки в репозиторий не входит: самостоятельная сборка получит другую подпись и не установится поверх APK из Releases без удаления приложения.
